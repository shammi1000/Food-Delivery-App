# 🍔 Food-Delivery-App

A sleek and intuitive food delivery and restaurant menu application that allows users to browse dishes, view detailed descriptions, and explore menu items with a smooth and responsive user experience.

---

## 🚀 Features

* 🍽️ Browse restaurant menu items
* 🔍 Search and filter dishes
* 📄 Detailed food descriptions
* 🛒 Add to cart functionality
* 📱 Fully responsive design
* ⚡ Fast and smooth navigation

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Framework:** Create React App
* **Languages:** JavaScript, HTML, CSS

## ⚙️ Installation & Setup

1. Clone the repository

```bash
git clone https://github.com/shammi1000/Food-Delivery-App.git
```

2. Navigate to the project directory

```bash
cd Food-Delivery-App
```

3. Install dependencies

```bash
npm install
```

4. Run the development server

```bash
npm start
```

The application will run at:

```
http://localhost:3000
```

---

## 🧪 Run Tests
